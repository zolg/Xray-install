# Xray-install c актуальными для России geosite/geoip

Для удобства использования жестко закодированные в [оригинальном скрипте](https://github.com/XTLS/Xray-install) URL geosite/geoip заменены на 
[russia-v2ray-rules-dat](https://github.com/runetfreedom/russia-v2ray-rules-dat)

Других отличий от оригинального установщика нет, для установки самого xray-core искользуются те же самые бинарники.
